# SousChef AI

AI-центр управления франчайзинговой ресторанной сетью: ИИ как су-шеф управляющего — готовит анализ, находит потери и подсказывает, а решения принимает человек.
ИИ анализирует данные сети, находит проблемы и инсайты, считает их финансовый эффект, предлагает гипотезы,
проверяет их экспериментами на группе ресторанов и замеряет результат. Поверх этого работают AI-агенты,
которые автоматизируют ручную работу.

**MVP: AI-менеджер запасов** — ТТК, фудкост, закупочные цены, инвентаризации, списания, риск дефицита,
AI-сводка директора по процессам ресторана и чат с AI-ассистентом по данным. Пилот — 3 ресторана, данные из iiko / r_keeper / 1С:ERP.

## Быстрый старт

Нужны Docker и make.

```bash
make up        # PostgreSQL, Redis, backend (миграции), frontend + демо-сеть: 12 ресторанов, 6 месяцев данных
```

Интерфейс: http://localhost:5173, API: http://localhost:8000/docs.
Демо-пользователи (пароль `demo12345`): `admin@demo.local` (УК), `analyst@demo.local` (аналитик УК),
`director1..3@demo.local` (директора R01–R03).

Разработка без Docker (нужны PostgreSQL 16, uv, Node 22): роли и базы — `infra/postgres/init.sql`, затем
`make migrate seed load-demo`, `make dev-backend`, `make dev-frontend`. Файлы демо-сети с описанием заложенных
аномалий: `make demo-data` (папка `demo-data/`, см. [docs/11-demo-network.md](docs/11-demo-network.md)). Проверки: `make check` (линтеры, типы, тесты, сборка).
