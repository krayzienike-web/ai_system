# 04. Импорт данных из XLS/CSV

## Цель

Директор или аналитик УК загружает выгрузку из учетной системы и через минуту видит результат,
а при ошибке — понятный отчет «строка 154: неизвестная единица 'кг.' у товара 'Сыр Моцарелла'».

| Шаблон | Ключевые колонки | Частота |
|--------|------------------|---------|
| `restaurants` | код, название, город, формат, дата открытия | разово |
| `products` | код, название, категория, базовая ед., срок годности | при изменениях |
| `suppliers` | код, название, ИНН | при изменениях |
| `menu_items` | код, название, категория, цена | при изменениях |
| `recipes` (ТТК) | блюдо/п/ф, ингредиент, брутто, нетто, ед., действует с | при изменениях |
| `sales` | дата, ресторан, блюдо, кол-во, выручка, скидка | день/неделя |
| `receipts` | дата, ресторан, № накладной, поставщик, товар, кол-во, ед., цена, сумма, НДС | день/неделя |
| `transfers` | дата, откуда, куда, товар, кол-во | по факту |

Шаблоны лежат в `templates/` с примером заполнения и листом-инструкцией.

## Маппинг колонок — ключ к реальным выгрузкам

Реальные отчеты iiko/r_keeper не совпадают с нашими шаблонами. Поэтому:
1. При загрузке система распознает колонки (по словарю синонимов + LLM-подсказка) и показывает предпросмотр маппинга.
2. Пользователь подтверждает; маппинг сохраняется как **профиль источника** («Отчет iiko: Движение товаров»)
   и дальше применяется автоматически.
3. Названия товаров из файла сопоставляются с номенклатурой сети (`ProductAlias`): точное совпадение →
   нечеткое (trigram) → предложение ИИ → подтверждение человеком. Несопоставленное не теряется — уходит в M7.

## Пайплайн

```
upload → store raw file (S3) → ImportBatch(pending)
  → parse (тип по расширению, кодировка, разделитель, лист)
  → map columns (профиль источника)
  → validate в staging-таблицах:
       схема/типы → справочные ссылки → единицы → бизнес-правила (дата в периоде, кол-во ≥ 0, сумма = цена×кол-во ±1%)
  → отчет: ошибки (блокируют) / предупреждения (не блокируют)
  → publish: транзакционная замена данных (ресторан × период × тип) — идемпотентно
  → trigger пересчет аналитики для затронутых ресторанов/периодов
```

- Большие файлы обрабатываются фоново, прогресс показывается в UI.
- Каждый batch можно откатить.
- Дубли файлов определяются по хэшу.
