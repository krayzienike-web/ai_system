# Каталог ИИ-агентов — черновик для обсуждения (19.11.2026)

Черновик к презентации функционала. Его надо согласовать с заказчиком; после этого принятое переносится
в [07](../07-risks-questions-ideas.md) и в презентацию.

Схема у всех агентов одна ([ADR 0010](../adr/0010-agents-code-collects-human-decides.md)): повод и цифры считает код,
текст пишет модель со сверкой чисел, решение принимает человек.

**Обозначения**
- ✅ — агент сделан.
- 📋 — агент запланирован.
- **MVP** — работает на данных, которые уже грузятся (продажи, закупки, накладные, инвентаризации, списания,
  перемещения, техкарты, находки, задачи, проверки).
- **+X** — нужна новая выгрузка X.
