# 11. Демо-сеть

Синтетическая сеть для разработки, тестов и показа (этап 2 роадмапа): **12 ресторанов, 20.04–18.10.2026**,
полные инвентаризации вечером 19.04 (стартовая) и 01.06, 03.08, 01.10; остаток инвентаризации — на конец дня. Генератор детерминирован: одно и то же зерно дает
те же байты (`backend/app/demo/generator.py`).

```
make demo-data   # файлы в demo-data/ + anomalies.json
make load-demo   # загрузить в демо-тенант через тот же импорт, что у пользователя
```

## Как устроена «физика»

- Расход по ТТК = продажи блюд × брутто из техкарты.
- Реальный расход = расход по ТТК × (1 + нормальные потери 0,5–3% по товару) × заложенные аномалии.
- Учетный остаток (iiko) движется по ТТК, фактический — по реальности; инвентаризация показывает оба и выравнивает учет.
- Поставки — по дням поставщика, на горизонт до следующей поставки с запасом.

Поэтому фактический расход, посчитанный из файлов (остаток на начало + приход − списания − остаток на конец),
расходится с ТТК ровно на нормальные потери плюс аномалию — это проверяется тестом `tests/test_demo_generator.py`.

## История и работа по находкам (`load-demo`)

Прототип показывает то, что посчитал бэкенд по демо-сети (ADR 0007). Поэтому `load-demo` после загрузки файлов:

1. **Пересчитывает находки за последний квартал по неделям.** Движок 12 раз запускается «на понедельник» по данным,
   известным к прошедшему воскресенью (`engine.run(as_of=…)`). После каждого запуска аналитик подтверждает
   найденное, кроме двух находок, оставленных для «Проверки находок»: рост цены лосося и фудкост «Лосося на гриле».
   Пропуск закупок R09 движок находит только в «сегодняшнем» запуске, поэтому он тоже ждет проверки.
   Каждый запуск сохраняет точку недельного тренда, так что линия «найденный потенциал» на главной настоящая.
2. **Заводит находки по заложенным аномалиям модулей, которых еще нет** (M4, M5): руккола R01, списания перед
   пересчетом R01, хлеб R07, пересорт сыров R11. Это находки «заведено аналитиком». Аномалии M7 (пропуск закупок R09,
   суп без техкарты) с 27.10.2026 находит движок. Цифры в них посчитаны из загруженных данных (`app/demo/showcase.py`), ключи совпадают с будущими
   ключами движка, и модуль, когда появится, заберет их себе.
3. **Добавляет работу по находкам:**
   - идущую проверку по моцарелле;
   - предложенную проверку по говядине;
   - две завершенные проверки: руккола сработала, по хлебу результат непонятен;
   - задачи директоров (выполненные с отчетом, открытые, просроченные).

«Сегодня» демо-сети — 20.10.2026: вторник после последнего дня данных (18.10).
