# Каталог ИИ-агентов

Согласован с заказчиком 20.11.2026 (документ «Каталог ИИ-агентов» и презентация функционала).
Всего — 76.
Агенты работают по схеме [ADR 0010](adr/0010-agents-code-collects-human-decides.md): повод и цифры считает код,
текст пишет модель со сверкой чисел, решение принимает человек. Уже сделаны и работают в «Помощнике»: О-01…О-09, Ф-01;
остальные — бэклог. Обезличивание данных для внешней модели — [ADR 0011](adr/0011-self-hosting-and-pseudonymized-llm.md).
