# 02. Бренд и дизайн-система SousChef AI

## 1. Платформа бренда

**Суть:** су-шеф управляющего. Готовит все заранее (анализ, расчеты, черновики решений), замечает то, что ускользает,
говорит коротко и по делу. Решает человек.

**Обещание:** «Покажем, где ресторан теряет деньги, и поможем добавить их к прибыли — простыми шагами».

**Ценности**
| Ценность | В продукте |
|----------|------------|
| Деньги, а не графики | Каждый вывод начинается с суммы в рублях |
| Ясность | Простой язык, один вывод на блок, термины — в подсказках |
| Честность | «Насколько уверены» и «откуда цифра» у каждого вывода; «не знаем» лучше, чем выдумка |
| Партнерство | Тон помощника, а не контролера: «что улучшилось» всегда на виду |
| Действие | Рядом с каждым выводом — один понятный следующий шаг |

**Характер:** спокойный, компетентный, теплый, точный. **Не:** надзиратель, айтишник, рекламщик.

## 2. Голос и тон

| Правило | Так | Не так |
|---------|-----|--------|
| Деньги словами | «Теряем 38 тыс ₽ в месяц» | «−38 тыс ₽/мес» |
| Вывод первым | «Моцареллы уходит на 9% больше нормы — и это растет третий период подряд» | «Расход сверх ТТК: 9,1%» |
| Без жаргона | «Можно добавить к прибыли», «находки», «где пробуем» | «Эффект», «инсайты», «тестовая группа» |
| Без обвинений | «Похоже, порции сыра больше нормы» | «Нарушение ТТК поваром» |
| Конкретное действие | «Две недели взвешивать сыр на раздаче» | «Оптимизировать процесс» |
| Неуверенность прямо | «Уверены средне: данных за одну инвентаризацию» | «Уверенность: средняя» |
| Глаголы на кнопках | «Взять в работу», «Утвердить и поставить задачи» | «ОК», «Применить» |

### Словарь

| Понятие | Пишем | Подсказка (по наведению) |
|---------|-------|--------------------------|
| finding | находка | То, что ИИ заметил в данных: проблема или возможность |
| effect | можно добавить к прибыли = перестать терять + дополнительно заработать | Оценка в рублях в месяц. Не «вернуть»: пользователи не понимают, что и откуда возвращается |
| confidence | насколько уверены | Сколько данных и насколько они полные |
| theoretical usage | расход по норме (ТТК) | Сколько продукта должно уйти по техкартам проданных блюд |
| actual usage | фактический расход | Остаток в начале + приход − остаток в конце |
| test group | где пробуем | Рестораны, где вводим изменение |
| control group | с чем сравниваем | Похожие рестораны без изменения |
| confidence interval | скорее всего от … до … | Диапазон, в котором почти наверняка лежит эффект |
| п.п. | пункта | Разница между процентами |

## 3. Логотип

- **Знак:** колпак шефа из трех дуг в скругленном квадрате цвета «Базилик», в правом верхнем углу — искра «ИИ»
  цвета «Шафран». Колпак — отрасль, искра — помощник, который подсказывает.
- **Логотип:** знак + «SousChef» (Unbounded, 600) + метка «AI» (Onest, 600, в рамке).
- Минимальный размер знака — 20 px. Охранное поле — половина высоты знака.
- На темном фоне знак инвертируется: белый квадрат, базиликовый колпак.

Файл: `frontend/src/brand/Logo.tsx` (SVG, без внешних ресурсов).

## 5. Типографика

| Роль | Шрифт | Где |
|------|-------|-----|
| Акцент | **Unbounded** 600 | Логотип, заголовки страниц, крупные суммы |
| Интерфейс и текст | **Onest** 400 / 500 / 600 | Все остальное |
| Цифры | Onest с `tabular-nums` | Таблицы, суммы, проценты |

Оба шрифта — Google Fonts с кириллицей; Onest создан для русского интерфейса.
Шкала: 12 · 14 · 16 · 18 · 22 · 28 · 36 · 48 px. Основной текст — 15–16 px, не меньше 12 px нигде.

## 6. Форма и пространство

- Сетка 4 px; отступы 8 · 12 · 16 · 24 · 32 · 48.
- Скругления: 10 px (кнопки, поля), 16 px (карточки), 24 px (главные панели).
- Тени мягкие и только у «поднятых» элементов (панели, всплывающие окна); обычные блоки отделяются фоном.
- Ширина контента — до 1280 px; текст — до 70 знаков в строке.

## 7. Анатомия блока

Каждый смысловой блок построен одинаково:

1. **Вопрос** — заголовок блока («Где ресторан теряет деньги?»).
2. **Ответ** — одна фраза с выводом и суммой.
3. **Визуализация** — где хорошо и плохо видно без легенды.
4. **Действие** — одна главная кнопка рядом с данными.
5. **Откуда** — мелко: период, источник, «насколько уверены».

## 8. Компоненты

| Компонент | Назначение |
|-----------|-----------|
| `AppShell` | Боковое меню (ПК) / нижняя панель или меню (телефон), верхняя строка с поиском и ИИ |
| `QuestionBlock` | Анатомия блока из п. 7 |
| `MoneyHero` | Главная сумма экрана с плавным нарастанием цифр |
| `ActionCard` | «Дело на неделю»: что сделать, сколько добавит к прибыли, срок, одна кнопка |
| `FindingRow` | Находка в списке: название, сумма словами, процесс, этап цикла |
| `BulletScale` | Одна шкала «мой ресторан / сеть / норма» с зонами «хорошо — плохо» |
| `Waterfall` | «Лесенка» баланса: приход → расход по норме → списания → не объяснено |
| `RankList` | Рейтинг с полосами и изменением позиции |
| `CycleSteps` | Этапы «Нашли → Делаем → Проверяем → Результат» |
| `ProcessMap` | 8 процессов: статус иконкой и словом, клик открывает находки процесса |
| `TrendChart` | График с подписанным выводом над ним |
| `ConfidenceNote` | «Насколько уверены» словами и причиной |
| `Term` | Термин с пунктирным подчеркиванием и объяснением по наведению |
| `StatusPill`, `Button`, `Tabs`, `Dialog`, `Drawer`, `Toast`, `Skeleton`, `EmptyState` | Базовые элементы |

## 9. Визуализация данных

| Вопрос | Форма | Не используем |
|--------|-------|---------------|
| Сколько и это много? | Крупная сумма + сравнение с прошлой неделей | Плитки без контекста |
| Я лучше или хуже сети и нормы? | `BulletScale` | Три числа в строку |
| Как менялось? | Линия + вывод над графиком | Графики без вывода |
| Из чего сложилась потеря? | `Waterfall` | Таблица-баланс |
| Кто впереди, кто отстает? | `RankList` | Таблица из 8 колонок |
| Где по процессам? | `ProcessMap` (иконка + слово + сумма) | Тепловая карта без подписей |
| Подробности, доказательства | Таблица с сортировкой, итогом, ссылкой на документ | — |

Правила: одна ось; не больше двух рядов на графике; подписи прямо у линий; цвет никогда не единственный носитель смысла;
у каждого графика есть табличный вид.

## 10. Движение

| Где | Что | Зачем |
|-----|-----|-------|
| Главная сумма | Плавное нарастание числа 600 мс | Привлечь внимание к главному |
| Появление экрана | Блоки появляются по очереди, шаг 50 мс, смещение 8 px | Показать порядок чтения |
| Шкалы и полосы | Заполнение 500 мс | Сравнение «читается» в движении |
| «Взять в работу» | Карточка сжимается и улетает в «Задачи», счетчик задач подпрыгивает | Связь находки и задачи |
| Этапы цикла | Переход между этапами со сменой цвета | Видно продвижение |
| Чат | Панель выезжает, ответ печатается | Ощущение живого помощника |

Длительности: 150 мс (наведение), 250 мс (раскрытие), 400–600 мс (акценты). Плавность: `cubic-bezier(0.2, 0.8, 0.2, 1)`.
При `prefers-reduced-motion` анимации отключаются: значения появляются сразу.
