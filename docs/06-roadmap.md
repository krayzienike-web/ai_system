# 06. Роадмап MVP

Каждый этап заканчивается работающим, показываемым результатом (вертикальный срез), а не «слоем».
Оценки — ориентир для одного full-stack разработчика с ИИ-ассистентом.

| Этап | Содержание | Критерий готовности | Оценка |
|------|-----------|---------------------|--------|
| **0. Проработка** | Видение, доменная модель, спецификация аналитики, архитектура, ADR, ответы на открытые вопросы | Документы согласованы, вопросы из [07](07-risks-questions-ideas.md) закрыты | сейчас |
| **1. Фундамент** | Скелет репо, Docker Compose, CI, БД + миграции, auth, роли, RLS, тенанты/рестораны | `make up` поднимает систему; тест: директор не видит чужой ресторан ни через API, ни через БД | 1 нед |
| **2. Демо-сеть + импорт** | Генератор синтетической сети (10–15 ресторанов, 6 мес, заложенные аномалии); шаблоны XLSX; пайплайн импорта с валидацией и отчетом об ошибках | Демо-данные загружаются через UI по шаблонам; битый файл дает понятный отчет | 1,5 нед |
| **3. Аналитический движок** | Себестоимость, витрины, M1–M7, findings, эффект и приоритет | Тест: детекторы находят ≥ 90% заложенных аномалий при ≤ 10% ложных | 2 нед |
| **4. Дашборды** | УК: «деньги на столе», рейтинг ресторанов, инсайты, drill-down до накладной. Директор: свои KPI, свои инсайты, позиция в сети | Сценарий демо проходится кликами | 1,5 нед |
| **5. AI-слой** | LLM Gateway, narrator, copilot-чат с tools, логирование, evals | Ответы ИИ содержат только числа из расчетов (eval в CI) | 1,5 нед |
| **6. Цикл экспериментов** | Гипотезы, подбор групп, утверждение, задачи, замер DiD | Полный цикл на демо-данных (с «доливом» данных после эксперимента) | 1,5 нед |
| **7. Полировка демо** | Сценарий для инвестора, онбординг, стенд в облаке, загрузка реальных данных пилотного клиента | Прогон демо за 10 мин без сбоев; реальные данные 1 сети загружены | 1 нед |

Итого ≈ 10 недель до инвесторского демо на реальных + синтетических данных.
Быстрый путь: этапы 1–4 + упрощенный 5 (narrator без чата) дают «показываемый» прототип за ≈ 6 недель.

## Порядок разработки внутри этапа

1. Тесты/фикстуры на демо-данных → 2. backend-сервис → 3. API (OpenAPI) → 4. сгенерированный клиент → 5. UI → 6. e2e.

## После MVP

Интеграция iiko API → AI-автозаказ → Telegram-бот директора → модуль «Финансы (P&L)» →
AI HR (графики, текучесть, ФОТ) → маркетинг/гость (отзывы, CRM) → контроль качества (чек-листы, фото-аудит).
