# ADR 0009. Находка доходит до директора только через решение УК

Статус: принято 03.11.2026 (решение заказчика, комментарий к прототипу). Уточняет [ADR 0006](0006-tasks-execution-and-traceability.md).

## Контекст

До этого решения подтвержденная на «Проверке находок» находка ресторана сразу становилась видна директору: в
«Моей неделе», «Всех находках», «Сводке недели». Директор мог сам нажать «Беру в работу». «Ждут решения» у УК
содержали только проверки к запуску и просроченные задачи.

Заказчик: «иначе ломается процесс». Должно быть так: проверка (подтверждают или отклоняют) → подтвержденная
находка в «Ждут решения» → УК ставит ее на директора.

## Решение

1. **Проверка.** Аналитик подтверждает или отклоняет находку, как раньше.
2. **«Ждут решения» → «Решить по находке».** Подтвержденная находка, по которой еще нет ни задачи, ни проверки
   изменения, попадает в «Ждут решения» — и находка ресторана, и сетевая. УК решает:
   - **поставить задачу** директору (сетевая — всем или части ресторанов) со сроком и шагами;
   - или **предложить проверку изменения**.
   Решенная находка из раздела уходит. Счетчик «Ждут решения» учитывает и эти находки.
3. **Директор видит находку только после задачи.** Находка ресторана видна директору, когда на его ресторан
   поставлена задача по ней. До этого ее нет ни в «Моей неделе», ни в «Находках», ни в «Сводке недели», ни в
   ответах чата. Сетевую находку директор по-прежнему не видит; он получает задачу.
4. **«Беру в работу» у директора убирается.** Задачу ставит УК; директор ее исполняет (ADR 0006). «Не согласен»
   в сводке остается как обратная связь УК о данных. Это не оспаривание: задача остается в силе.
5. **Сводка директора** строится из находок, которые ему видны (с задачей). «Задачи по находке» и «на столе» —
   по ним же.

## Последствия

- Правила видимости — в одном месте на сервере (`insights.visible` и выборки обзоров и сводки), с тестами
  изоляции. Прототип повторяет их по записанным ответам (ADR 0007).
- Демо-сеть: витрина ставит задачи по части подтвержденных находок, остальные ждут решения у УК.
- e2e и сценарий показа (docs/14) меняются: директор начинает с «Задач», УК — с «Ждут решения».
- docs/10 (экраны), docs/08 (сводка), docs/05 (цикл) — обновить вместе с кодом.

## Уточнения при реализации (05.11.2026, ревью этапа 6.1)

- «Поставить задачу» — одна задача: отмеченные шаги — ее чек-лист, срок на выбор; сетевая находка — выбранным
  ресторанам (по умолчанию всем). Аналитику раздел виден, задачу ставит администратор УК.
- Директору без задач экраны не говорят «норма»: «Задач нет», «Задач по находкам от управляющей компании пока нет».
  Изменение сумм за неделю («потенциал вырос на …») директору не показывается: сохраненные итоги недели считают и
  находки без задачи.
- Основание предложений ИИ по находке ресторана называет только находки, видимые ее директору.
