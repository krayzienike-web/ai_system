# ADR 0002. Расчеты детерминированно, LLM — поверх результатов

**Статус:** предложено

## Контекст
Ценность продукта — в деньгах, которые можно проверить. LLM ошибается в арифметике и может выдумать числа.

## Решение
- Все метрики, отклонения, эффекты считает аналитический слой (SQL/Python) с unit-тестами.
- Результат — структурированные `Finding` с evidence.
- LLM получает findings и данные только через инструменты (tool use) с правами пользователя; пишет объяснения,
  гипотезы, ответы в чате. Structured output для машинно-обрабатываемых результатов.
- Пост-проверка чисел в ответах, логирование `AiRun`, eval-набор на демо-сети в CI.
- Никакого произвольного SQL от LLM в MVP.

## Последствия
Надежность и проверяемость. Чат умеет только то, что покрыто инструментами — набор инструментов расширяем итеративно.
