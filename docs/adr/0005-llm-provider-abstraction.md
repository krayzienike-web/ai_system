# ADR 0005. Абстракция LLM-провайдера

**Статус:** предложено (зависит от ответа на вопрос Q6 в [07](../07-risks-questions-ideas.md))

## Контекст
Лучшее качество рассуждений и tool use — у frontier-моделей (например, Claude), но для клиентов в РФ возможны
ограничения доступа и требования к размещению данных.

## Решение
- Внутренний интерфейс `LLMGateway` (chat, tool use, structured output, стриминг) с адаптерами провайдеров.
- Промпты версионируются в репозитории; выбор модели — конфигурацией на уровне задачи (narrator / copilot / hypothesis).
- В LLM передаются только агрегаты и справочники, без персональных данных.
- Eval-набор позволяет сравнить провайдеров на наших задачах объективно.

## Последствия
Небольшая цена абстракции; свобода смены провайдера без переделки продукта.
