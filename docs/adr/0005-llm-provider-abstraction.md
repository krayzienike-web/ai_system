# ADR 0005. LLM-провайдер: Claude API за тонким шлюзом

**Статус:** принято (передача агрегированных данных в зарубежный LLM согласована)

## Контекст
Чат, сводки и объяснения инсайтов требуют качественного tool use и рассуждений на русском языке.
Нужны контроль стоимости, воспроизводимость и защита от выдуманных чисел.

## Решение
- Основной провайдер — **Claude API** через официальный Python SDK `anthropic`.
- Модели по задачам (настраиваются конфигурацией):

| Задача | Модель | Режим |
|--------|--------|-------|
| Чат с ассистентом | `claude-opus-5-5` | стриминг, tool use, adaptive thinking |
| AI-сводка директора / сети | `claude-opus-5-5` | structured output; пакетная генерация по расписанию через Message Batches API (дешевле на 50%) |
| Объяснение инсайтов, гипотезы | `claude-opus-5-5` | structured output |
| Массовые простые задачи: сопоставление названий товаров, распознавание колонок | `claude-haiku-5-5` | structured output, батчи |

- **Prompt caching**: стабильный системный промпт и описания инструментов идут первыми и кэшируются.
- **Устойчивость**: обработка `stop_reason` (в т.ч. `refusal`) и серверный fallback на другую модель, ретраи 429/5xx.
- Тонкий интерфейс `LLMGateway` (chat / tools / structured / stream) остается: он нужен для логирования `AiRun`,
  лимитов, eval'ов и на случай смены провайдера для будущего AI HR. Отдельные адаптеры других провайдеров в MVP не делаем.
- Промпты версионируются в репозитории; eval-набор на демо-сети запускается в CI при их изменении.

## Последствия
Лучшее доступное качество ответов. Нужно контролировать стоимость (лимиты на пользователя, батчи для сводок, кэширование)
и не передавать персональные данные.

## Реализация (этап 5, 28.10.2026)
- `app/ai/gateway.py` — `Gateway.complete`: проверка дневного лимита пользователя (`FAI_AI_REQUESTS_PER_USER_DAY`,
  по журналу `ai_runs`), вызов модели, запись вызова в `ai_runs` — и при отказе, обрыве по токенам или сбое.
  Сообщения и инструменты — в формате Messages API, без своего промежуточного формата.
- `app/ai/claude.py` — единственный модуль, импортирующий `anthropic` (контракт import-linter):
  - системный промпт помечен для кэширования;
  - адаптивное мышление, effort задается явно (`FAI_AI_EFFORT`, по умолчанию `medium`);
  - при отказе API сам повторяет запрос на резервной модели (`fallbacks: "default"`), кроме Haiku;
  - повторы при 429 и 5xx — средствами SDK.
- `FakeModel` — заглушка модели для тестов и для работы без ключа.
- `FAI_AI_PROVIDER=off` (по умолчанию): модели нет, и чат отвечает по правилам.
- `FAI_AI_PROVIDER=claude` и `ANTHROPIC_API_KEY`: работает модель из `FAI_AI_MODEL`.
- Промпты — `app/ai/prompts/<имя>.v<N>.md`. Изменение промпта — это новый файл, а не правка старого. В журнале
  записаны версия и хэш промпта.
