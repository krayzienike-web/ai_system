# ADR 0001. Модульный монолит на Python/FastAPI + PostgreSQL

**Статус:** предложено

## Контекст
Прототип для инвестора и первых клиентов; маленькая команда; основная сложность — аналитика, ML и LLM.

## Решение
- Один backend-сервис (FastAPI) с явными модулями и правилами зависимостей + один worker для фоновых задач.
- PostgreSQL 16 как единственное хранилище состояния (Redis — только очередь/кэш).
- React SPA на фронтенде, клиент генерируется из OpenAPI.

## Альтернативы
- Микросервисы — преждевременно, дорого в эксплуатации.
- Node.js/NestJS backend — слабее экосистема для аналитики и ML.
- ClickHouse для аналитики — избыточно на объемах франшизы (миллионы строк Postgres тянет); вернемся при масштабе.

## Последствия
Быстрая разработка, простой деплой. Границы модулей нужно дисциплинированно соблюдать (линтер импортов).
