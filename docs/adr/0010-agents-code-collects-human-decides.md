# ADR 0010. Агенты: код собирает, модель пишет, человек решает

Дата: 11.11.2026. Статус: принято. Развивает [ADR 0002](0002-deterministic-analytics-llm-on-top.md) и
[ADR 0008](0008-ai-proposes-code-verifies-human-approves.md).

## Контекст

Заказчик попросил агентов, которые сами проходят несколько шагов на данных MVP и готовят работу людям
([07](../07-risks-questions-ideas.md), «ИИ-агенты на данных MVP»). Ключа API пока нет (Q12), а пилоту
нужна предсказуемость: агент не должен ни придумывать числа, ни делать что-то без человека.

## Решение

1. **Что предложить, решает код.** Агент — детерминированная функция над данными сети (`app/agents/`): повод
   (до пересчета 2 дня, задача просрочена, выгрузка не свежая по правилу «Свежесть данных»), список с числами и предложение действия. Тесты — как
   у метрик: на демо-сети агент находит заложенный повод и ничего лишнего.
2. **Модель только пишет текст.** Через шлюз (`app/ai/agent_writer.py`), по фактам сообщения; каждое число текста
   сверяется с фактами (`ai.verify.unsupported`). Не прошло, модели нет или бюджет кончился — текст пишут правила
   (`app/agents/texts.py`). Модуль `agents` не импортирует `ai`: писатель передается ему функцией, как у сводки.
3. **Человек решает.** У сообщения два ответа: «Создать задачу» (создает задачу или меняет срок) и «Не нужно».
   Перенос срока — только администратор УК. Ничего не отправляется наружу и не меняется без этого нажатия.
4. **Видимость как у находок.** Сообщение для директора строится только из того, что директор и так видит: свой
   ресторан, находки с задачей (ADR 0009), без чисел других ресторанов. RLS — по ресторану; сообщения для УК
   директору не видны.
5. **Идемпотентность.** У сообщения есть ключ повода (агент + ресторан + задача/день); повторный прогон обновляет
   новое сообщение и не трогает решенное. Повод исчез (данные пришли, задачу сделали) — новое сообщение «устарело».

6. **Решенное не возвращается по тому же поводу.** Повод входит в ключ (у просроченной задачи — ее срок): если
   УК скрыла предложение перенести срок, о той же задаче с тем же сроком агент больше не напомнит; новый срок —
   новый повод. Список, запрошенный вручную, можно запросить снова: устаревший или скрытый становится новым.
7. **Сверка чисел — по всем фактам сообщения.** Число в тексте модели должно быть в фактах, но не обязательно у
   того же товара: «P2 — 15 000 ₽» пройдет, если 15 000 — остаток P3. Поэтому список с числами по товарам всегда
   от кода, а модель пишет только вводный текст и не перечисляет список (промпт `agent.v1`).

## Последствия

- Агенты работают без ключа API: тексты по правилам. С ключом тексты станут живее, смысл не изменится.
- Новые агенты (№ 2–6, 8, 10–11) добавляются той же схемой: функция повода, факты, правила текста, решение.
- Доставка — пока только экран «Помощник»; почта и мессенджер — после ответа на Q23 и Q38.
