# Открытые вопросы к заказчику

Реестр вопросов, на которые нужен ответ. **Правило для ИИ-разработчика:** при начале каждого этапа роадмапа
просмотреть этот файл и задать заказчику вопросы, у которых наступил срок «нужно к этапу».
Получен ответ → перенести в «Закрытые» с датой и обновить затронутые документы.

Заказчик видит эти вопросы, план и бэклог идей в веб-штабе проекта и отвечает прямо там:
https://claude.ai/artifact/VTKH9eTedipRYBNoyWaB9q. Реестр здесь и штаб держим одинаковыми.
