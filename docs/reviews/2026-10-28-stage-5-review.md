Сами ревьюеры код не меняли. Исправления внес разработчик, каждое — с тестом ([реестр](../13-testing.md),
TC-AI-25…33).

Чек-лист и метки — как в [ревью 26.10.2026](2026-10-26-code-review.md).

**Итог.**
- **Сервер.** Утечек чужих данных через инструменты не нашлось: каждый вызов инструмента — в своей транзакции на
  чтение под RLS пользователя, находки идут через `insights.visible`. Но проверка чисел (принцип 1) пропускала
  целые 0…10 вместе с единицами («4%», «2 п.п.», «в 3 раза»), а через вопрос и текст ошибки инструмента можно было
  провести любое число. Это блокер, исправлен. Еще шесть мест «исправить»:
  - транзакция запроса висела во время вызова модели;
  - журнал `ai_runs` открывал разговоры директоров УК;
  - разговор ломался после отказа модели;
  - в историю попадали неподтвержденные ответы;
  - два одновременных вопроса в один разговор сталкивались;
  - сбой инструмента ронял весь вопрос.
- **Интерфейс.** Нарушений ADR 0007 нет. Схема API совпадает с сервером, прототип работает, рабочая сборка без
  демо-данных. Исправить пришлось три вещи:
  - раздачу чанков после выкладки;
  - отмену вопроса при закрытии чата;
  - озвучивание статуса и ответа для скринридера.
