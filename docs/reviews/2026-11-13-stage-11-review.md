# Код-ревью: агенты третьей тройки, «Меню», «Задачи сети», файл 1С в демо (этап 11)

Дата: 13.11.2026. Коммиты `8daf7ac..HEAD`. Два агента-ревьюера: бэкенд и фронтенд. Одно замечание высокое —
бэкенд, п. 1. Каждое исправление — с тестом.

## Бэкенд

1. **Высокое: письмо поставщику могло обрушить утренний проход агентов.** Поставщик с суммой экономии от
   3 000 ₽ в месяц, у которого каждый товар экономит меньше 500 ₽, давал письмо без товаров. Текст по правилам
   падал, и вся сеть оставалась без сообщений всех агентов. Исправлено: без товара для письма письма нет.
   Тест — `test_many_small_savings_give_no_letter_and_break_nothing` (TC-AG-38).
2. **Техкарта бралась по строкам товара, а не по версии блюда.** Товар, убранный из новой техкарты, все равно
   получал «новую норму». Исправлено: версия берется целиком (`catalog.recipes.lines_on`), строки одного товара
   в версии суммируются. Тест — TC-AG-39 (салат с новой техкартой без картофеля).
3. **Норма, уже измененная после периода находки, повышалась второй раз.** Исправлено: такие техкарты не
   трогаем и перечисляем отдельной строкой «Уже изменены…». Тест — TC-AG-39 (бургер).
4. **Себестоимость продаж за месяц была занижена.** Блюда, в которые товар входит через полуфабрикат, не
   учитывались; без цены писалось «≈ 0 ₽». Исправлено:
   - месяц считается разложением каждого проданного блюда (`explode`) с новыми и старыми техкартами;
   - без закупок в окне сумма не пишется.

   Тесты — TC-AG-39 (через полуфабрикат + 26,40 ₽), `test_a_card_without_a_price_says_no_sum`.
5. **«Выгрузки отстают» срабатывало при отставании на день.** Рестораны выгружают в разное время. Исправлено:
   - порог — от 2 дней (`LAG_DAYS`);
   - продажи считаются только с начала проверки, поэтому текст «продаж за время проверки нет» теперь верен.

   Тест — `test_a_day_behind_is_not_a_stopped_export` (TC-AG-40).
6. **Порядок списков зависел от базы.** Исправлено: новые поставщики сортируются еще и по имени поставщика,
   блюда — еще и по коду. Без этого заметка переписывалась при каждом прогоне. Повторный прогон — TC-AG-43.
7. **Сообщения о проверке и письма поставщику обновляются каждый день.** Это решение, а не ошибка: «день 9 из 28»
   и окно 8 недель до последней накладной должны быть верны в день, когда УК читает сообщение. С ключом API
   модель переписывает такой текст раз в день — один вызов на сообщение в сутки, в пределах бюджета.
8. **«Меню» загружало всю историю сети на каждый запрос.** Исправлено: `analytics/menu.load` читает только
   меню, техкарты и закупки с продажами за окно.
9. **Агент техкарт читал меню и продажи заново на каждую находку.** Исправлено: данные сети загружаются один
   раз за прогон.
10. **«21 ресторан нашей сети закупают».** Исправлено: форма глагола зависит от числа.
11. **Пробелы в тестах.** Закрыты тестами пп. 1–5. Отдельного теста на «Еще товаров…» (больше 6 товаров в
    письме) нет — бэклог тестировщика.

## Фронтенд

1. **В прототипе файл раздваивался после «Проверить заново».** У разных демо-входов свои записанные ответы.
   Исправлено: проверенный файл становится файлом сессии для всех входов, записанная копия больше не
   показывается. Тест — `demo.units.test.ts`: у аналитика файл один, id не повторяются.
2. **В прототипе директор мог проверить чужой файл.** Исправлено: файл другого ресторана — 404, как на
   сервере. Тест — `demo.units.test.ts` «is not found for a director».
3. **Пороги движка были вписаны в текст «Меню».** Исправлено: сервер отдает `popularity` и `window_days`
   (`M2_ME_POPULARITY`, `M2_WINDOW_DAYS`), экран пишет их значения. Тест — TC-AN-61.
4. **«Задать единицы» видели те, кто задать не может.** Исправлено: для них кнопка — «Открыть отчет».
5. **Прототип снимал ошибку по словам сообщения.** Исправлено: по полю `fix` (товар и единица). В комментарии
   отмечено отличие: прототип не перечитывает файл, поэтому новые незнакомые названия появиться не могут.
6. **Кнопки «Напомнить» без названия задачи для скринридера.** Исправлено: `aria-label` с задачей и
   рестораном.
7. **Можно было напоминать много раз за день.** Исправлено: после напоминания кнопка — «Напомнили сегодня».
8. **Директор не видел напоминания УК.** Исправлено: в «Моих задачах» — «УК напомнила дд.мм».
9. **Округление в таблице «Меню».** Исправлено: себестоимость и маржа — с копейками, доля меньше 1% — с
   десятыми.
10. **Матрица пропадала при смене ресторана.** Исправлено: прошлая матрица видна, пока грузится новая.

Тесты пп. 4, 6, 7 — `e2e/review-11.spec.ts`. Пп. 8–10 — вид без отдельного теста: «УК напомнила», копейки и
прошлая матрица на время загрузки проверены вручную и сквозным прогоном (`e2e/`, 44 теста).
